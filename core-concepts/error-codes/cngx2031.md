# CNGX2031

## A cngxInput without a [formField] binding

This warning is emitted when a native `input`, `textarea` or `select` with `cngxInput` is the control of a Signal Forms field and nothing binds the field to it. `cngx-form-field` projects the label, hint, error and ARIA state onto the control, so the field looks wired, but the value only flows through `[formField]`. Without it, typing never reaches the field value, the field stays pristine and untouched, validation never sees the input, and the error summary has no bound control to focus.

```html
<!-- WARNING: the input renders and takes ARIA, but f.name never changes. -->
<cngx-form-field [field]="f.name">
  <label cngxLabel>Name</label>
  <input cngxInput />
</cngx-form-field>
```

The check reads the field's own list of `[formField]` bindings (`formFieldBindings`, Signal Forms 21.1 and later). A display-only input with a static `readonly` attribute or a hand-bound `[value]` warns too: the field it sits in still expects to be bound.

### Fixing the warning

Bind the field on the control:

```html
<cngx-form-field [field]="f.name">
  <label cngxLabel>Name</label>
  <input cngxInput [formField]="f.name" />
</cngx-form-field>
```

### Why the field does not bind the control for you

The value atoms of `@cngx/common/interactive` (checkbox, toggle, radio group and friends) expose a `value` signal, so `cngx-form-field` syncs them without `[formField]`. A native element has no such signal, and a second binding path next to `[formField]` would compete with Signal Forms for the value, the touched state and the focus target. One binding, declared on the control, keeps the field the single source of truth.

### Debugging the warning

The message starts with `CNGX2031: [cngxInput]` followed by the field path. The check runs after render in development mode only, once per field: two inputs or two `cngx-form-field`s on one field warn once. Reactive Forms fields (`adaptFormControl()`) and test mocks expose no binding list and never warn. In production the warning is stripped.

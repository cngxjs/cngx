# CNGX3008

## Action button toasts configured twice

### Why

`CngxActionButton` has `[toastSuccess]` / `[toastError]` inputs, and the same element also carries `[cngxToastOn]`. Both react to the same async state, so every success or failure shows two toasts.

### Fix

Use one of the two: either the `[toastSuccess]` / `[toastError]` inputs on the button, or `[cngxToastOn]` with its own inputs.

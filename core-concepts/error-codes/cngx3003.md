# CNGX3003

## Alert overflow label does not contain its visible text

### Why

`CngxAlertStack` shows a "+N more" trigger when alerts overflow. Its visible text comes from `alertOverflowVisible(count)` and its accessible name from `alertOverflow(count)`, both in `CNGX_FEEDBACK_I18N`. The accessible name does not contain the visible text, so a speech-input user who says the visible words cannot activate the trigger (WCAG 2.5.3, Label in Name). The message shows both strings. It fires once per pair.

### Fix

Override both keys together, so the accessible name includes the visible label:

```typescript
provideFeedbackI18n({
  announcements: {
    alertOverflowVisible: (count) => `+${count}`,
    alertOverflow: (count) => `+${count} more alerts`,
  },
});
```

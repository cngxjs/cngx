# CNGX3002

## No state source for a feedback bridge

### Why

`CngxAlertOn`, `CngxBannerOn` and `CngxToastOn` turn an async state into an alert, a banner or a toast. Each reads the state from its own input (`[cngxAlertOn]`, `[cngxBannerOn]`, `[cngxToastOn]`) or, when the input is unbound, from a `CNGX_STATEFUL` provider on the host. After the first render it found neither, so it has nothing to watch and never shows feedback.

### Fix

Bind the state explicitly:

```html
<button [cngxToastOn]="save.state" toastSuccess="Saved">Save</button>
```

Or put the directive on a component that provides `CNGX_STATEFUL` (for example `CngxActionSelect` or `CngxTimeline`) and leave the input unbound.

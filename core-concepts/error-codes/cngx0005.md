# CNGX0005

## Language pack provided below the root injector

### Why

`provideCngxI18n()` ran in a child environment injector, such as a lazy route's `providers`. The copy of every cngx lib is resolved once in the root injector and reads the root pack, so the child call switches `CNGX_LOCALE`, `CNGX_DIRECTION` and `<html lang>` / `<html dir>` for that subtree while the labels, announcements and messages stay in the root language.

### Fix

Call `provideCngxI18n()` once, in the application config, and remove the call from the child injector. Then pick the tool for what the child call was meant to do:

- **Different copy in one subtree:** use the per-token overrides there, for example `provideTabsI18n(withTabsI18nLabels({ tabsLabel: 'Bereiche' }))`. They apply on top of the pack, key by key, also in a subtree.
- **Different number and date format in one subtree:** `provideLocaleAt(...)`.
- **Switching the whole app's language at runtime:** pass a `Signal` to `withPack` (or `withPartialPack`) and set it from the part of the app that changes the language.

See "One pack per app" in the i18n guide.

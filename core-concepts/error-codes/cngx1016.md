# CNGX1016

## Status without an accessible name

### Why

`<cngx-status>` has no `[label]` and no `aria-label` or `aria-labelledby` on the host. Assistive technology then has nothing to read, and a sighted user sees only a coloured dot.

### Fix

Set a visible label:

```html
<cngx-status tone="success" label="Online" />
```

Or name the host with `aria-label` when the text sits elsewhere on screen.

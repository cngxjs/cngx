# CNGX1018

## Tag group label without a semantic list

### Why

`<cngx-tag-group>` has a `[label]` but `[semanticList]` is not `true`. The label then lands as `aria-label` on a plain `<div>`, which has no role, so assistive technology does not announce a list or its item count.

### Fix

Add `[semanticList]="true"` to expose `role="list"` together with the label, or remove `[label]` when the group is not a list.

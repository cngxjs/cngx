# CNGX0901

## Duplicate node id in a tree

### Why

`flattenTree` derives an id for every node with its `idFn` (`nodeIdFn` on `CngxTreeSelect`). Ids must be unique across the whole forest: each flat node stores the ids of its ancestors, so two nodes with one id corrupt those chains and with them expansion, visibility and selection.

### Fix

Make the id function return a different id for every node, for example a database key, or the parent's id joined with the node's own. When nodes share a value, derive the id from the node path rather than the value.

# CNGX1007

## Non-numeric chart data without a summary accessor

### Why

`<cngx-chart>` builds its auto-summary and the screen-reader data table from one number per data item. With no `[summaryAccessor]` bound, it converts each item with `Number(item)`. The first item is not numeric, so the summary and the table fall back to `NaN`.

### Fix

Bind an accessor that picks the value:

```html
<cngx-chart [data]="sales" [summaryAccessor]="revenueOf">...</cngx-chart>
```

with `revenueOf = (d: Sale) => d.revenue`. Or pass a numeric array as `[data]`.

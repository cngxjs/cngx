# CNGX1030

## Duplicate tree selection key

### Why

`createTreeController` got the same key from `keyFn` for two nodes. Selection is tracked by key, so the two nodes share one selected state and lookups by key find only the later node. The error appears once per key.

### Fix

Return a key from `keyFn` that is unique across the tree. Without `keyFn` and without a `defaultKeyFn` from `provideTreeConfig`, the node value itself is the key, so two nodes with equal primitive values collide.

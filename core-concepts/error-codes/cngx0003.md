# CNGX0003

## No argument for a placeholder

This warning is emitted when `formatMessage` from `@cngx/core/i18n` replaces the `{name}` placeholders of a message and the arguments it got have no `name`.

Every cngx message with variable parts (`'Column {position}'`, `'{count} rows selected'`) goes through `formatMessage`. It replaces each `{name}` with `args[name]`: numbers through the locale's number format, strings wrapped in bidi isolation marks. cngx passes a fixed set of argument names for each key, and a message that uses a different name has nothing to substitute.

cngx leaves the placeholder in the output, so the gap is visible instead of silently empty. It still reaches users and screen readers: a header reads `Spalte {pos}`, a live region announces `{anzahl} Zeilen ausgewählt`. The usual cause is a translation that renamed a placeholder:

```ts
provideCngxI18n(
  withPartialPack({
    locale: 'de',
    treetable: {
      // WARNING: cngx passes { position }; "{pos}" has no argument
      unlabeledColumn: 'Spalte {pos}',
    },
  }),
);
```

### Fixing the warning

#### Option 1: Use the placeholder names of the English section

A translation keeps the placeholder names of the English message; only the text around them changes. Each lib exports its English section (`CNGX_TREETABLE_LANGUAGE_EN`, ...), and its JSDoc lists the placeholders of every key:

```ts
treetable: { unlabeledColumn: 'Spalte {position}' }
```

The same applies to per-token overrides that take a message, and to messages you format yourself.

#### Option 2: Pass the missing argument

In your own `formatMessage` calls, add the argument the message expects, or remove the placeholder from the message:

```ts
formatMessage('{count} of {total} loaded', { count: loaded(), total: total() }, locale());
```

### Debugging the warning

The message names the placeholder and quotes the whole template, for example `no argument for {pos} in "Spalte {pos}"`. Search your pack files and `formatMessage` calls for that template.

The check runs in development mode only and is not deduplicated: it fires once per missing placeholder on every format. Placeholders match `{` followed by word characters and `}`; there is no escape syntax, so a literal `{word}` in copy is treated as a placeholder too. A plural message formatted without a numeric `count` also triggers [CNGX0002](cngx0002.html); a locale that is not a BCP 47 tag is [CNGX0001](cngx0001.html).

# CNGX0003

## No argument for a placeholder

### Why

A message contains a `{name}` placeholder, but the arguments it was formatted with have no `name`. CNGX leaves the placeholder in the output, so the gap is visible instead of silently empty.

### Fix

Pass the missing argument, or remove the placeholder from the message. When the message comes from your own language pack or a per-token override, compare its placeholders with the English template: a translation must use the same placeholder names.

# CNGX1002

## Lifecycle key bound on `[cngxAudio]`

### Why

`[cngxAudio]` plays earcons for DOM events (`click`, `focus`, `blur`, `pointerenter`, `pointerleave`, `submit`, `change`, `input`). The binding spec contains async-status keys such as `pending` or `success`. Those are not DOM events, so the directive never fires them.

### Fix

Move the status keys to `[cngxAudioStatus]`, which plays earcons on async-state transitions:

```html
<button [cngxAudio]="'click:tap'" [cngxAudioStatus]="'success:done, error:fail'" [state]="save.state">
  Save
</button>
```

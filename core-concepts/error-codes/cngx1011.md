# CNGX1011

## Grid recycler without columns

### Why

`injectRecycler({ layout: 'grid', ... })` needs the number of columns to map an index to a row. `columns` is not set, so the recycler falls back to one column and lays the grid out as a list.

### Fix

Pass `columns`, as a number or as a function that reads a signal for a responsive grid:

```ts
injectRecycler({ layout: 'grid', columns: () => this.columnCount(), ... });
```

# CNGX1011

## Grid recycler without columns

This error is reported when `injectRecycler` is called with `layout: 'grid'` and no `columns`.

In grid mode the recycler virtualises rows, not items. It turns the scroll position into a row range using `estimateSize` as the row height, then multiplies by the column count to get the item range it renders, the placeholders before and after it, and the overscan (which it rounds up to whole rows). The column count is the one number it cannot derive: the grid's CSS decides how many items fit in a row, and the recycler does not measure the layout.

Without `columns` the recycler falls back to one column. The CSS still lays out several items per row, so the recycler renders only one item for every visible row: most of the viewport is filled with placeholders, and `scrollToIndex` computes row offsets for the wrong row. Nothing throws:

```ts
// ERROR: grid layout without a column count
readonly recycler = injectRecycler({
  scrollElement: '.gallery-scroll',
  totalCount: () => this.photos().length,
  estimateSize: 180,
  layout: 'grid',
});
```

### Fixing the error

#### Option 1: Pass a fixed column count

When the grid has a fixed number of columns, pass it:

```ts
readonly recycler = injectRecycler({
  scrollElement: '.gallery-scroll',
  totalCount: () => this.photos().length,
  estimateSize: 180,
  layout: 'grid',
  columns: 4,
});
```

#### Option 2: Pass a function for a responsive grid

`columns` also accepts a function. The recycler reads it inside a `computed()`, so a function that reads a signal makes the column count reactive:

```ts
private readonly wide = injectMediaQuery('(min-width: 960px)');

readonly recycler = injectRecycler({
  scrollElement: '.gallery-scroll',
  totalCount: () => this.photos().length,
  estimateSize: 180,
  layout: 'grid',
  columns: () => (this.wide() ? 4 : 2),
});
```

Keep the CSS grid and the `columns` value derived from the same breakpoint, so the two never disagree.

### Debugging the error

The message starts with `CNGX1011: injectRecycler(): layout: "grid" requires explicit` and ends with `Falling back to columns=1.` It does not name the component; search for `injectRecycler` calls with `layout: 'grid'`.

The check runs in development mode only, once per `injectRecycler` call, when the recycler is created. It checks only that `columns` is present; a function that returns `0` or a value that does not match the CSS is not detected.

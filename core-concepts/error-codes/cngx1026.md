# CNGX1026

## Submenu popover without position fallbacks

### Why

The popover of a submenu has no `position-try-fallbacks`. A submenu that opens towards the viewport edge then clips instead of flipping to the other side. The warning appears once per document.

### Fix

Wire the recommended fallback chain:

```ts
import { CNGX_SUBMENU_TRY_FALLBACKS } from '@cngx/common/interactive';
```

```html
<div cngxPopover [positionTryFallbacks]="CNGX_SUBMENU_TRY_FALLBACKS">...</div>
```

# CNGX3011

## Icon-only tabs without an icon template

### Why

`<cngx-tab-group>` resolved `iconLayout` to `'only'`, which hides the tab labels visually and shows only the icon. No `*cngxTabIcon` template is provided, so the tabs render with neither a visible icon nor a visible label. The accessible names stay intact.

### Fix

Provide an icon template:

```html
<cngx-tab-group iconLayout="only">
  <ng-template cngxTabIcon let-tab>...</ng-template>
  ...
</cngx-tab-group>
```

Or use `iconLayout` `'start'`, `'end'` or `'top'` to keep the labels visible.

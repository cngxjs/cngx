# CNGX3004

## Raw error text shown as error detail

### Why

`CngxAlertOn`, `CngxToastOn`, `CngxBannerOn` and `CngxActionButton` can append a detail to their error message. Without `withErrorDetail`, development builds append the raw error text (`err.message` or a thrown string) so you see what failed, and production builds append nothing. Raw error text is written for developers: an HTTP status line, an English server string, a stack fragment. It is neither translated nor safe to show to users. The warning fires once per application the first time a raw detail shows.

### Fix

Map errors to user-facing text:

```typescript
provideFeedback(
  withErrorDetail((error) =>
    error instanceof HttpErrorResponse && error.status === 409 ? 'Someone else changed this record.' : undefined,
  ),
);
```

Return `undefined` to show the message without a detail.

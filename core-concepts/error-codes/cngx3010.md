# CNGX3010

## Sidenav auto mode without a layout

### Why

`<cngx-sidenav mode="auto">` switches between side and over presentation based on the size of its container. It found no `<cngx-sidenav-layout>` ancestor and no `[cngxContainer]` ancestor, so it has no container size to read and renders as `over`.

### Fix

Wrap the sidenav and its content in `<cngx-sidenav-layout>`, or put it inside an element carrying `[cngxContainer]` (`@cngx/common/layout`) whose size should drive the mode. If the sidenav should always overlay, set `mode="over"`.

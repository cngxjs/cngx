# CNGX1005

## No state source for `[cngxAudioStatus]`

### Why

`[cngxAudioStatus]` reads the async state from its `[state]` input or, when the input is unbound, from a `CNGX_STATEFUL` provider on the host. After the first render it found neither, so it has no transitions to play earcons for.

### Fix

Bind the state explicitly:

```html
<button [cngxAudioStatus]="'success:done'" [state]="save.state">Save</button>
```

Or put the directive on a component that provides `CNGX_STATEFUL` and leave `[state]` unbound.

# CNGX1052

## Button toggle under both a single and a multi group

This error is thrown when a `[cngxButtonToggle]` finds both a single-select group (`<cngx-button-toggle-group>`) and a multi-select group (`<cngx-button-multi-toggle-group>`) above it in the injector tree.

A button toggle has no value state of its own; it reads and writes through its group. The two groups have different contracts: the single group holds one `value` and renders its toggles as radios (`role="radio"`, `aria-checked`), the multi group holds a `selectedValues` array and renders them as pressed buttons (`aria-pressed`). A toggle that sees both cannot tell which contract to follow, and either choice would leave the other group out of sync with what the button shows. It throws instead of guessing.

This usually happens when one group is nested inside the other:

```html
<!-- ERROR: the inner toggle sees both groups -->
<cngx-button-toggle-group label="View" [(value)]="view">
  <cngx-button-multi-toggle-group label="Filters" [(selectedValues)]="filters">
    <button cngxButtonToggle value="open">Open</button>
  </cngx-button-multi-toggle-group>
</cngx-button-toggle-group>
```

### Fixing the error

Give each group its own toggles and place the groups side by side, not nested:

```html
<cngx-button-toggle-group label="View" [(value)]="view">
  <button cngxButtonToggle value="list">List</button>
  <button cngxButtonToggle value="grid">Grid</button>
</cngx-button-toggle-group>

<cngx-button-multi-toggle-group label="Filters" [(selectedValues)]="filters">
  <button cngxButtonToggle value="open">Open</button>
  <button cngxButtonToggle value="closed">Closed</button>
</cngx-button-multi-toggle-group>
```

If the layout needs the groups visually nested, wrap them in a plain container element and position them with CSS; the injector tree follows the template nesting, not the visual one.

### Debugging the error

In a production build the message is the bare code `CNGX1052`; the check still runs there.

The toggle resolves its group once, when it is created. Nesting is not always visible in a single template: a component that renders a multi group and projects content can receive a toggle written inside a single group in the parent template. Follow the toggle's element injector up through the content projection to find the second group. A toggle with no group at all reports [CNGX1053](cngx1053.html).

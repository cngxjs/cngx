# CNGX2003

## Filter value references an unknown field

### Why

The filter tree bound to `value` contains expressions whose `field` key matches none of the entries in `fields`. The message lists the keys. Such an expression has no field definition to evaluate against, so it evaluates to `false` for every item.

### Fix

Add the missing keys to `fields`, or drop the expressions from the value. A stored filter that outlived a renamed or removed field is the usual cause; migrate it when you load it.

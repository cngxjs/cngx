# CNGX4001

## Treetable column has no header label

### Why

A `cngx-treetable` column has neither a `columnLabels` entry nor a projected `*cngxHeader` template. In development the header shows the raw column key so you can spot it; a production build shows the `unlabeledColumn` text instead (`Column 2` by default), because a data key is not a label a user should read or a screen reader should announce. The warning fires once per column key.

### Fix

Give the column a label, either through the treetable labels or the language pack:

```typescript
provideTreetable(withTreetableLabels({ columnLabels: { size: 'Size' } }));
```

or project a header template for that column with `*cngxHeader`.

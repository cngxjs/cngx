# CNGX1010

## Chart preset without an accessible name

### Why

The meter presets (`<cngx-mini-bar>`, `<cngx-donut>`, `<cngx-bullet>`, `<cngx-deviation-bar>`) render with `role="meter"` or `role="img"`. After the first render the host had no accessible name: no `[label]`, no `[aria-label]` and no `aria-labelledby`. Assistive technology then announces the value without its subject.

### Fix

Name the preset, with the input the warning names:

```html
<cngx-mini-bar [value]="cpu()" label="CPU load" />
<cngx-bullet [value]="revenue()" aria-label="Revenue against target" />
```

An `aria-labelledby` attribute that points at a visible heading works too.

# CNGX3025

## Tab without a label string

This warning is emitted when a `<cngx-tab-group>` holds one or more `cngxTab` directives whose `label` input resolves to no string (unbound, `undefined` or `''`). One warning is written per tab group; it lists the 1-based position of every such tab.

The tab group needs the label string in more places than the visible label. The live region speaks it after a move, a rollback or a refused switch, the close button is named `Close "<label>"`, and the overflow list renders it as the row text. A `*cngxTabLabel` template is markup, not text, so none of these surfaces can read it.

Without a label string every one of those surfaces falls back to the tab's position, `Tab 2`. The tab button itself is named from the rendered `*cngxTabLabel` template through `aria-labelledby` when there is one, so the name a screen reader user hears on focus and the name the announcements use no longer match. Without a template the tab has no visible label and no name source at all.

```html
<!-- WARNING: the second tab binds no [label] string -->
<cngx-tab-group [attr.aria-label]="settingsLabel()">
  <div cngxTab [label]="profileLabel()">...</div>
  <div cngxTab>
    <ng-template cngxTabLabel>{{ billingLabel() }}</ng-template>
  </div>
</cngx-tab-group>
```

### Fixing the warning

Bind `[label]` on every `cngxTab`. Keep the `*cngxTabLabel` template when the visible label needs markup (an icon, a count, emphasis); the template still renders, and `[label]` supplies the text the announcements, the close button and the overflow list need.

```html
<cngx-tab-group [attr.aria-label]="settingsLabel()">
  <div cngxTab [label]="profileLabel()">...</div>
  <div cngxTab [label]="billingLabel()">
    <ng-template cngxTabLabel><strong>{{ billingLabel() }}</strong></ng-template>
  </div>
</cngx-tab-group>
```

A dynamic label must be a non-empty string by the first render; an empty string counts as no label.

### Debugging the warning

The message starts with `CNGX3025: [cngx-tab-group] tab(s) without a [label] string at position` and lists each position with its name source: "named by its *cngxTabLabel template" or "no name source". The tab group's host element is passed as the second console argument, so the browser console links the instance.

The check runs in development mode only, once per tab group, after the first render. A tab added later, or a label cleared later, is not reported.

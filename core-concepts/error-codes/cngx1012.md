# CNGX1012

## Per-index size estimate on a large recycler

### Why

`estimateSize` is a plain function `(index) => number` and the list holds more than 10 000 items. The recycler calls the function for every index on every frame it recomputes offsets, which costs O(n) per frame.

### Fix

Pass a fixed number or a `Signal<number>` as `estimateSize`, and let `[cngxMeasure]` correct the real heights of the rendered rows. Keep the function form for short lists only.

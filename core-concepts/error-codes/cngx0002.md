# CNGX0002

## Plural message without a numeric count

This warning is emitted when `formatMessage` from `@cngx/core/i18n` formats a plural message (a `CngxPluralMessage` such as `{ one: '{count} error', other: '{count} errors' }`) and the arguments have no `count`, or `count` is not a `number`.

A plural message picks its form with `Intl.PluralRules` of the active locale, and the only input it reads is `count`. Without a number there is no plural category to select, so cngx uses the `other` form.

Nothing breaks visibly in English, where `other` is often the form you see anyway, which is why this goes unnoticed. In languages with `one`, `few` or `many` forms the text reads wrong. When `count` is missing altogether and the template contains `{count}`, the placeholder also stays in the output; a `count` that is a string is still substituted as text. Two common causes: a count that arrives as a string (a route parameter, an attribute), and a translated pack that turns a plain message into a plural one for a key cngx formats without `count`:

```ts
// The treetable formats `unlabeledColumn` with { position }, never with { count }.
provideCngxI18n(
  withPartialPack({
    locale: 'de',
    treetable: {
      // WARNING: plural message on a key that gets no "count" argument
      unlabeledColumn: { one: 'Spalte {count}', other: 'Spalten {count}' },
    },
  }),
);
```

### Fixing the warning

#### Option 1: Pass `count` as a number

In your own `formatMessage` calls, pass the count as a number and convert strings first:

```ts
formatMessage(message, { count: Number(route.snapshot.params['count']) }, locale());
```

#### Option 2: Keep the message shape of the key

A pack key that is a plain string with other placeholders in the English section (`unlabeledColumn: 'Column {position}'`) has to stay a plain string in a translation. Only keys whose English value is a plural object are formatted with `count`. Compare with the section's English constant, for example `CNGX_TREETABLE_LANGUAGE_EN`:

```ts
treetable: { unlabeledColumn: 'Spalte {position}' }
```

### Debugging the warning

The message quotes the `other` form of the plural message, for example `CNGX0002: formatMessage(): plural message without a numeric "count" argument: "{count} errors"`. Search your pack and your `formatMessage` calls for that text.

The check runs in development mode only and is not deduplicated: it fires on every format, so a message formatted inside a `computed()` logs again each time that computed re-runs. When `count` is missing and the `other` form contains `{count}`, [CNGX0003](cngx0003.html) fires for the same call because the placeholder has no argument either; fixing the count clears both. A string `count` fires only this warning.

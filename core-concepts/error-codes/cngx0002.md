# CNGX0002

## Plural message without a numeric count

### Why

A plural message (`{ one: '{count} error', other: '{count} errors' }`) picks its form from the `count` argument with `Intl.PluralRules`. When `count` is missing or not a number, CNGX cannot pick a form and uses `other`.

### Fix

Pass `count` as a number: `formatMessage(message, { count: errors.length }, locale)`. A count that arrives as a string (from a route parameter or an input attribute) needs a `Number(...)` first.

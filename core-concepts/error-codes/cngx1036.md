# CNGX1036

## Native Popover API not available

This warning is emitted when `CngxPopover` or `CngxTooltip` opens in a browser that does not implement the HTML Popover API (`HTMLElement.showPopover()`).

`CngxPopover` builds on the native `popover` attribute: `show()` calls `showPopover()`, which puts the panel in the top layer above every stacking context and gives light dismiss and focus handling to the browser. Every CNGX overlay that opens through `CngxPopover`, from plain popovers and tooltips to menus and the select family's panels, depends on it. The API ships in all current evergreen browsers; older browsers and some embedded web views lack it, and so does jsdom.

Without the API, `show()` does nothing after this warning: the popover or tooltip stays closed, and other open popovers are left alone. Once a polyfill is loaded, the next `show()` opens it normally.

### Fixing the warning

#### Option 1: Load the polyfill

Install `@oddbird/popover-polyfill` and import it once, before the application bootstraps:

```bash
npm install @oddbird/popover-polyfill
```

```ts
// polyfills.ts, or the first line of main.ts
import '@oddbird/popover-polyfill';
```

If you use a `polyfills.ts` file, list it in the `polyfills` option of the build target in `angular.json`.

#### Option 2: Stub the API in unit tests

jsdom does not implement the Popover API. In a component test that opens a popover, stub the methods on the panel element before opening it:

```ts
const panel = fixture.nativeElement.querySelector('[cngxPopover]') as HTMLElement;
Object.assign(panel, { showPopover: vi.fn(), hidePopover: vi.fn(), togglePopover: vi.fn() });
```

### Debugging the warning

The message starts with `CNGX1036: CngxPopover: The native Popover API is not supported in this browser` (or `CNGX1036: CngxTooltip: ...` when a tooltip opened first) and includes the install and import lines. Run `typeof HTMLElement.prototype.showPopover` in the browser console; anything other than `"function"` confirms it.

The check runs in development mode only, on each `show()` of a popover or tooltip, and logs once per document: after the first warning, further popovers and tooltips in the same document stay silent. It checks the element that opens, so a polyfill that loads after the first popover opened still leaves that one warning in the console.

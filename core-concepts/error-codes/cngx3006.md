# CNGX3006

## Mat-tabs aggregator slot half-wired

### Why

The aggregator decoration of `[cngxMatTabs]` renders a projected `*cngxMatTabAggregatorContent` template into the tab header, which needs both the template and a `ViewContainerRef` to mount it into. Exactly one of the two is supplied. The decoration falls back to plain text, and the projected template never renders. The message names the missing half.

### Fix

Wire both halves on the `[cngxMatTabs]` directive, or neither.

The library default only warns in development. To report the condition in production (telemetry, CI fail-fast), install your own sink:

```typescript
provideMatTabsConfig(withHalfWiredSlotSink((missing) => logger.warn('half-wired', missing)));
```

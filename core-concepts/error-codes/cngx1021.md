# CNGX1021

## Duplicate name in the error registry

### Why

`CngxErrorRegistry` already holds a scope or an aggregator with this name. The registry keeps the existing instance and ignores the new one, so lookups by name keep returning the first.

### Fix

Give each scope and each aggregator a unique name. To replace an instance on purpose, unregister the old one first, then register the new one.

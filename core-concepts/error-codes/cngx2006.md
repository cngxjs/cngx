# CNGX2006

## Input bound through DefaultValueAccessor

### Why

A `cngxNumericInput`, `cngxInputFormat` or `cngxInputMask` input is bound to a Reactive Forms control (`[formControl]`, `formControlName`), but Angular's `DefaultValueAccessor` picked it up instead of `CngxFormBridge`. The default accessor forwards the raw text of the element, so the control receives display strings instead of numbers, switches between raw and formatted text, or never sees the masked value. The message names the directive.

### Fix

Import `CngxFormBridge` from `@cngx/forms/controls` into the component that renders the input. `[ngModel]` is not supported on these directives; use `[(value)]` or Signal Forms instead.

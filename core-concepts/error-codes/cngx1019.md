# CNGX1019

## Two directives bind `aria-busy` on one element

### Why

`[cngxAsyncStatus]` and `[cngxAsyncClick]` sit on the same element. Both write `aria-busy` from their own state, so the attribute flips between two sources.

### Fix

Use one of them on the element. `[cngxAsyncClick]` already reflects its own action state; use `[cngxAsyncStatus]` when the element shows a state it does not start itself.

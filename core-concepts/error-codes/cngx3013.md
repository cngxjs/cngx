# CNGX3013

## Alternate placement ignored in an activity timeline

### Why

`<cngx-timeline>` has `placement="alternate"` and `mode="activity"`. An activity timeline is a feed that is scanned down one side, and alternating rows would break that scan, so every row renders on the start side and the placement is ignored.

### Fix

Use `mode="narrative"` if the timeline should alternate, or drop `placement="alternate"` for the activity feed.

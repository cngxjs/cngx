# CNGX1003

## Unrecognised event key on `[cngxAudio]`

### Why

The `[cngxAudio]` binding spec contains a key that is neither a supported DOM event nor an async status, so the directive ignores it and that earcon never plays.

### Fix

Use one of the supported events: `click`, `focus`, `blur`, `pointerenter`, `pointerleave`, `submit`, `change`, `input`. Check the spec for a typo, and for the `key:earcon` pair shape separated by commas.

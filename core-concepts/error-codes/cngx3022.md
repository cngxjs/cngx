# CNGX3022

## Data-grid part outside a data grid

This error is thrown when `<cngx-dga-row>`, `input[cngxDgaFilter]` or `[cngxDgaSortHeader]` from `@cngx/ui/data-grid-accordion` is created without a `<cngx-data-grid-accordion>` above it.

The parts share the state of the grid they sit in. A row takes its heading level from the grid and its open state from the grid's accordion, and lays its cells out on the grid's shared column tracks; the filter input writes its debounced term into the grid's filter; a sort header reads and changes the grid's sort and announces it. None of them holds that state itself. Without the grid a row has no columns to align to and the filter and sort controls change nothing, so the constructor throws instead of rendering parts that look wired but are not.

```html
<!-- ERROR: the filter sits above the grid, not in its header -->
<input cngxDgaFilter />
<cngx-data-grid-accordion columns="8ch 1fr">
  <cngx-dga-row panelId="a">...</cngx-dga-row>
</cngx-data-grid-accordion>
```

### Fixing the error

Put the parts inside the grid: sort headers and the filter in `<cngx-dga-header>`, the rows directly in the grid.

```html
<cngx-data-grid-accordion columns="8ch 1fr">
  <cngx-dga-header>
    <span cngxDgaCell cngxDgaSortHeader="id">ID</span>
    <span cngxDgaCell>Name <input cngxDgaFilter /></span>
  </cngx-dga-header>
  <cngx-dga-row panelId="a">...</cngx-dga-row>
</cngx-data-grid-accordion>
```

### Debugging the error

The message names the part, for example `CNGX3022: [cngxDgaFilter] must be placed inside <cngx-data-grid-accordion>.` In a production build the message is the bare code `CNGX3022`; the check still runs there.

The check runs once, in the constructor, and looks at the element and its ancestors. Angular resolves the parent from where the element is written in a template, not from where it ends up in the DOM. A parent that another component renders in its own template, around content you project into it, is not above the projected element.

# CNGX2020

## More than one main control in a field box

This warning is emitted when a `cngxFieldBox` from `@cngx/forms/field` has two or more direct-child form-field controls that are not marked `cngxPrefix` or `cngxSuffix`.

The box paints the state of one control, its main control: the first direct child that provides `CNGX_FORM_FIELD_CONTROL` and is not an affix. It writes that control's state as `data-invalid`, `data-disabled` and `data-readonly`, and a click on the box padding focuses it. Merging the states of two controls has no single right answer (is the box invalid when one of them is?), so the box does not try. Every further non-affix control is ignored: its invalid or disabled state never reaches the box.

```html
<!-- WARNING: two main controls, only the amount input paints the box -->
<span cngxFieldBox>
  <input cngxInput cngxNumericInput [formField]="f.amount" />
  <cngx-select [label]="'Currency'" [options]="currencies" />
</span>
```

### Fixing the warning

#### Option 1: Mark the extra control as an affix

When the second control qualifies the first one, such as a currency or unit picker, mark it `cngxPrefix` or `cngxSuffix`. It keeps its place in the row, and its own state no longer competes with the main control:

```html
<span cngxFieldBox>
  <input cngxInput cngxNumericInput [formField]="f.amount" />
  <cngx-select cngxSuffix [label]="'Currency'" [options]="currencies" />
</span>
```

#### Option 2: Give each control its own box or field

When both controls are values in their own right, such as a "from" and "to" pair, give each one its own `cngxFieldBox`, or its own `cngx-form-field` when each needs a label and its own errors.

### Debugging the warning

The message starts with `CNGX2020: [cngxFieldBox]` and states how many main controls the box found. The box element is passed as the second console argument; expand it in the browser console to see which box it is.

The check runs in development mode only, once per box, after its first render. A control that an `@if` adds later is not checked. Only direct children count: a control behind a wrapper element is not a main control, see [CNGX2021](cngx2021.html).

# CNGX1029

## Duplicate tree node id

### Why

`createTreeController` got the same id from `nodeIdFn` for two nodes. Every id lookup (expansion, focus, selection by id) then finds only the later node, and the earlier one is shadowed. The error appears once per id.

### Fix

Return an id from `nodeIdFn` that is unique across the whole tree, for example the record's primary key, or the path for records without one.

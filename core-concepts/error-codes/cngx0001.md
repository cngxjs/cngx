# CNGX0001

## Locale is not a BCP 47 tag

### Why

`formatMessage` and the language pack format numbers and plurals with `Intl`, which only accepts BCP 47 tags (`de`, `de-AT`, `zh-Hant-TW`). A tag `Intl` rejects, such as `de_DE` or an empty string, would make every message throw. CNGX formats it as English instead and warns once per tag.

### Fix

Use a BCP 47 tag with hyphens, not underscores. Check the `locale` of the active language pack and every locale you pass to `formatMessage` directly. `Intl.getCanonicalLocales(tag)` in the console tells you whether a tag is valid.

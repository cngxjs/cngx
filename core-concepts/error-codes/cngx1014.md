# CNGX1014

## Second dialog title or description registered

### Why

A `CngxDialog` references one title id (`aria-labelledby`) and one description id (`aria-describedby`). A second `cngxDialogTitle` or `cngxDialogDescription` registered while the first is still live. The newest registration wins, so the dialog is named or described by a different element than the first one.

### Fix

Keep one `cngxDialogTitle` and at most one `cngxDialogDescription` per dialog. For extra descriptive text, keep it inside the one description element.

# CNGX3005

## Mat-tabs decoration retry ceiling reached

### Why

`[cngxMatTabs]` decorates the Material tab buttons (`.mat-mdc-tab`) with error and rejection state. When a decoration needs a button that is not rendered yet, it retries after the next render, up to a fixed number of attempts. All attempts ran and the button never appeared, so the decoration stays missing until the next state change. The usual causes are a Material upgrade that changed the `.mat-mdc-tab` markup or a render stall in the consumer.

### Fix

Check that `<mat-tab-group>` renders its tab header and is not hidden behind a condition that stays false. After a Material upgrade, check whether the tab buttons still carry the `.mat-mdc-tab` class and report a CNGX bug if they do not.

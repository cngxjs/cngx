# CNGX1067

## Popover sheet without a popover

This error is thrown when `[cngxPopoverSheet]` from `@cngx/common/popover` is created on an element that does not also carry `[cngxPopover]`.

The sheet is not a surface of its own. It is a presentation of the popover on the same element: it reads the popover's open state, moves focus inside `show()`, releases the page inside `hide()` and lays the popover out as a bottom sheet or a fullscreen panel. Without a popover on that element there is nothing to open or lay out, so the constructor throws.

```html
<!-- ERROR: the sheet sits on a plain element -->
<div cngxPopoverSheet>
  <ul>...</ul>
</div>
```

### Fixing the error

Put both directives on the same element:

```html
<div cngxPopover #pop="cngxPopover" cngxPopoverSheet>
  <ul>...</ul>
</div>
```

A popover on a parent or a child element does not count; the sheet looks at its own element only.

### Debugging the error

The message reads `CNGX1067: [cngxPopoverSheet] must be placed on an element with [cngxPopover].` In a production build the message is the bare code `CNGX1067`; the check still runs there.

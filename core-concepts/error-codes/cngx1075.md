# CNGX1075

## Push drawer requested as modal

This warning is emitted when an element with `cngxDrawerPanel` from `@cngx/common/layout` combines `mode="push"` with `[modal]="true"`.

A push drawer lays the panel out next to the content and shifts the content aside. The content stays visible and in use while the drawer is open, so the panel cannot be modal: a modal panel would trap focus, make the content `inert` and lock its scrolling, which leaves a visible page the user cannot operate. `CngxDrawerPanel` therefore resolves a push panel to non-modal and ignores `[modal]="true"`. The drawer still opens and closes; Escape, the back gesture and a press outside the panel still close it. Nothing throws.

```html
<!-- WARNING: push is never modal -->
<nav [cngxDrawerPanel]="drawer" mode="push" [modal]="true">…</nav>
```

### Fixing the warning

For a modal drawer, overlay the content with `mode="over"` (modal by default). For a drawer next to the content, drop `[modal]`.

```html
<nav [cngxDrawerPanel]="drawer" mode="over">…</nav>
<nav [cngxDrawerPanel]="drawer" mode="push">…</nav>
```

### Debugging the warning

The message starts with `CNGX1075: [cngxDrawerPanel] mode="push" is never modal; [modal]="true" is ignored.` It is emitted whenever the panel reaches the push + modal combination, so a mode switch at runtime warns again.

The check runs in development mode only. In production the panel renders the same, without a warning.

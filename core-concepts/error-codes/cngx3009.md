# CNGX3009

## Data-grid-accordion row has more cells than columns

### Why

`CngxDataGridAccordion` lays out every row on one shared column template, taken from the header cells (or the first row). A row projects more cells than that template has tracks. The extra cells land in implicit grid tracks and the columns misalign without any other visible error. The message names the cell count and the track count. It fires once per accordion.

### Fix

Give every row the same number of cells as the header. If a row needs an extra column, add it to the header too.

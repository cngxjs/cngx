# CNGX1024

## Submenu directive without a menu item

### Why

`[cngxMenuItemSubmenu]` sits on an element that has no `[cngxMenuItem]`. The surrounding menu highlights and activates menu items only, so ArrowRight and activation never reach this submenu.

### Fix

Put `[cngxMenuItem]` and `[cngxMenuItemSubmenu]` on the same element.

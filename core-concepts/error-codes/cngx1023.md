# CNGX1023

## Option without a label

### Why

An option (`[cngxOption]`, or `<cngx-option>` in a select shell) has no `[label]` and no text content. Assistive technology has no name to announce for it, and a select trigger has nothing to display once it is chosen.

### Fix

Give the option text content or a `[label]`:

```html
<cngx-option [value]="de">Deutsch</cngx-option>
<cngx-option [value]="en" label="English"><img src="flag-en.svg" alt="" /></cngx-option>
```

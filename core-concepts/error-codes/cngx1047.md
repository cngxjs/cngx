# CNGX1047

## Step group outside a stepper

This error is thrown when a `[cngxStepGroup]` is created without a stepper above it in the injector tree.

A step group is a node in the stepper's step tree: it registers with the stepper's presenter and its child steps register through it. The group's collapsed state and its position in the tree both derive from the presenter. Unlike `[cngxStep]`, a group cannot fall back to an enclosing group alone: a nested group registers through its parent group, but the tree still needs a stepper at its root. Without one the constructor throws.

```html
<!-- ERROR: no stepper host above the group -->
<div cngxStepGroup label="Account">
  <div cngxStep label="Email">...</div>
</div>
```

### Fixing the error

Wrap the group, or the outermost group of a nested set, in an element that provides a stepper: `[cngxStepper]`, one of the `@cngx/ui/stepper` organisms (`<cngx-stepper>`, `<cngx-dot-stepper>`, `<cngx-text-stepper>`, `<cngx-progress-bar-stepper>`) or `[cngxMatStepper]`.

```html
<div cngxStepper>
  <div cngxStepGroup label="Account">
    <div cngxStep label="Email">...</div>
    <div cngxStep label="Password">...</div>
  </div>
  <div cngxStep label="Finish">...</div>
</div>
```

### Debugging the error

In a production build the message is the bare code `CNGX1047`; the check still runs there, because a group without a stepper cannot work.

The check runs once, in the group's constructor, and looks only at the injector. In a nested set only the outermost group reports this error: its constructor throws first and aborts the subtree, so fixing it reveals whether an inner group is misplaced too. A step inside the orphaned group does not report [CNGX1046](cngx1046.html): it finds the group and is satisfied, so this error is the only one for the whole subtree.

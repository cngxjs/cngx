# CNGX1064

## Popover sheet without a name

This warning is reported when a `[cngxPopoverSheet]` opens as a modal sheet or fullscreen panel and has nothing to name it: no `cngxPopoverSheetTitle` inside the panel and no `[labelledBy]` binding.

In the sheet and fullscreen presentations the popover host becomes `role="dialog"` with `aria-modal="true"`. A screen reader announces a dialog by its accessible name when focus moves into it. The sheet takes that name from `aria-labelledby`, which points at the registered `cngxPopoverSheetTitle` or at the id passed to `[labelledBy]`. With neither, the dialog has no name: VoiceOver and TalkBack announce only "dialog", and the user does not learn what opened.

```html
<!-- WARNING: the sheet has no title part and no labelledBy -->
<div cngxPopover cngxPopoverSheet #pop="cngxPopover">
  <ul>...</ul>
</div>
```

### Fixing the warning

#### Option 1: Add a title part

Mark the visible heading inside the panel. The sheet points `aria-labelledby` at it:

```html
<div cngxPopover cngxPopoverSheet #pop="cngxPopover">
  <header cngxPopoverSheetHeader>
    <h2 cngxPopoverSheetTitle>City</h2>
  </header>
  <ul>...</ul>
</div>
```

Put the title on the heading element itself, not on the header that also holds the close button: the name would otherwise include the button text.

#### Option 2: Bind an existing label

If the name already exists elsewhere inside the panel, pass its id:

```html
<div cngxPopover cngxPopoverSheet [labelledBy]="'city-heading'">
  <p id="city-heading">Pick a city</p>
  <ul>...</ul>
</div>
```

The element must sit inside the panel. While the sheet is open, every page sibling is `inert`, and a name taken from an inert element is not read reliably.

### Debugging the warning

The message reads `CNGX1064: [cngxPopoverSheet] opened as a modal sheet without a name. Add a cngxPopoverSheetTitle inside the panel or bind [labelledBy].`

The check runs in development mode only, once per sheet, when it first opens as a modal sheet. An anchored popover never warns, because it is not a dialog. In the Elements panel, the popover host carries `role="dialog"` and no `aria-labelledby` attribute while the sheet is open.

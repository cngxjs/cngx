# CNGX0004

## Registry key already registered

### Why

A keyed registry (`createKeyedRegistry`) received a second value under a key it already holds. The registry keeps the first value and ignores the second, so a swap can never leave two owners fighting over one key. The name before the colon in the message is the registry's `name` option.

### Fix

Give each registrant a unique key. When you do mean to replace the entry, call `unregister(key)` before registering the new value. Registering the same value under the same key twice is a no-op and does not warn.

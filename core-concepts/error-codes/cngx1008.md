# CNGX1008

## More than one chart overlay

### Why

`<cngx-chart>` renders a single `*cngxChartOverlay` template. More than one is projected, so only the first renders and the others are dropped.

### Fix

Compose all overlay content inside one `*cngxChartOverlay` template.

# CNGX1027

## Menu host is not focusable

### Why

`CngxMenu.focus()` was called, but the `[cngxMenu]` host has a negative `tabindex` (or none on an element that is not focusable). The browser ignores the focus call, so keyboard users stay where they were.

### Fix

Add `tabindex="0"` to the `[cngxMenu]` host.

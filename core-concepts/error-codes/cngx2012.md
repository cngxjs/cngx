# CNGX2012

## Filter tree root removed

This error is thrown when an internal update of the `@cngx/forms/filter-builder` tree tries to remove the root group.

The filter builder stores its tree as nested `FilterGroup` and `FilterExpression` nodes and addresses a node by a path of child indexes: `[]` is the root group, `[2, 0]` is the first child of the root's third child. The empty path addresses the root, and the tree cannot exist without it. The tree utilities that `createFilterBuilderState` runs on refuse to remove it.

### Fixing the error

The public API cannot trigger this error: `state.removeNode([])` is a no-op. To empty the builder, call `state.clear()`, which resets the tree to an empty root group. Seeing `CNGX2012` therefore means a CNGX bug. Open an issue at https://github.com/cngxjs/cngx/issues with the call that led to it.

### Debugging the error

The message reads `CNGX2012: removeAtPath(): cannot remove the root`. In a production build the message is the bare code `CNGX2012`; the check still runs there.

The stack trace leads to `removeAtPath`. Note the state mutator that ran and its path; those are what the issue needs.

# CNGX1025

## Submenu without a popover or menu

### Why

`[cngxMenuItemSubmenu]` has no submenu to open: neither its own input with `[submenuMenu]` is bound, nor does a wrapping component provide `CNGX_MENU_SUBMENU_WIRING`. The item stays inert and renders no `aria-haspopup` or `aria-expanded`.

### Fix

Bind the popover and the menu:

```html
<li cngxMenuItem [cngxMenuItemSubmenu]="subPopover" [submenuMenu]="subMenu">More</li>
```

Or use it inside a component that provides `CNGX_MENU_SUBMENU_WIRING`.

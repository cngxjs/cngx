# CNGX1013

## Recycler scroll element not found on first render

### Why

The recycler `scrollElement` is a selector that matched no element on the first render. The recycler watches the document and attaches as soon as an element matches, so a container that mounts later (an async-gated list, a skeleton swapped for content) still works. If the element never appears, the recycler never sees a scroll position.

### Fix

If the container mounts later on purpose, nothing is wrong. Otherwise check the selector against the rendered DOM, or pass an `ElementRef` or `HTMLElement` instead of a selector.

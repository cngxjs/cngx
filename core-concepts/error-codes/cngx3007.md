# CNGX3007

## Mat-tabs overflow could not anchor

### Why

`[cngxMatTabs]` mounts `<cngx-tab-overflow>` (the "More" popover) inside Material's tab header, `.mat-mdc-tab-header`. It retries after each render up to `anchorMaxAttempts` times (default 5). The header was never found inside the host, so the overflow falls back to a position next to `<mat-tab-group>`. The message names the number of attempts.

### Fix

Make sure `<mat-tab-group>` renders on the host, and is not gated behind a condition or a `@defer` block that never resolves. If the header renders later than usual, raise the budget:

```typescript
provideMatTabsConfig(withAnchorRetryAttempts(10));
```

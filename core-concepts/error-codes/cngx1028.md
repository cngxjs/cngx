# CNGX1028

## Reorder items without an index

### Why

`[cngxReorder]` found elements that match its `itemSelector` but carry no numeric `data-reorder-index`. Pointer and keyboard moves on those elements are ignored, because the directive cannot tell their position.

### Fix

Bind the index on every item:

```html
@for (item of items(); track item.id; let i = $index) {
  <li [attr.data-reorder-index]="i">...</li>
}
```

Or narrow `itemSelector` so it matches only the reorderable items.

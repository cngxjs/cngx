# CNGX1028

## Reorder items without an index

This warning is emitted when elements inside a `[cngxReorder]` host match its `itemSelector` but have no valid `data-reorder-index` attribute (a non-negative integer).

`CngxReorder` never reads positions from the DOM order. On `pointerdown` and on a modifier + arrow key press, it finds the item with `closest(itemSelector)` and parses that element's `data-reorder-index` as the `fromIndex`; during a drag it does the same for the element under the pointer to get the `toIndex`. The index is how a DOM element maps back to an entry in the `[cngxReorder]` array that `(reordered)` rearranges.

An item without a valid index parses to `-1`, and the directive drops the gesture. Dragging that item does nothing, it is not a drop target, and the keyboard shortcut is ignored, all without an error. The default `itemSelector` is `[data-reorder-index]`, so this usually happens after `itemSelector` is set to a class, or when the index is bound to something that is not a number:

```html
<ul [cngxReorder]="tasks" itemSelector=".task" (reordered)="tasks.set($event.next)">
  @for (task of tasks(); track task.id) {
    <!-- WARNING: matches ".task" but has no data-reorder-index -->
    <li class="task">
      <button cngxReorderHandle [attr.aria-label]="moveLabel(task)">⋮⋮</button>
      {{ task.title }}
    </li>
  }
</ul>
```

### Fixing the warning

#### Option 1: Bind the index on every item

Use the `@for` index, not an id; the directive needs the position in the array:

```html
@for (task of tasks(); track task.id; let i = $index) {
  <li class="task" [attr.data-reorder-index]="i">
    <button cngxReorderHandle [attr.aria-label]="moveLabel(task)">⋮⋮</button>
    {{ task.title }}
  </li>
}
```

The handle's `aria-label` is user-facing copy; route it through your own i18n.

#### Option 2: Narrow `itemSelector`

If the selector also matches elements that are not reorderable (a header row, a placeholder), make it match only the items, or drop the custom selector and rely on the default `[data-reorder-index]`.

### Debugging the warning

The message counts the offending elements and quotes the selector, for example `[CngxReorder] 3 element(s) match itemSelector ".task" but carry no non-negative integer data-reorder-index`. Run `host.querySelectorAll('.task')` in the console and look for elements without the attribute or with a value that does not start with a non-negative integer.

The check runs in development mode only, once per directive, after the first render, and only over the items present at that time; items added later are not checked. An empty list does not warn. It parses each index the way the gestures do (`parseInt`, non-negative), so an empty or negative value is reported and a value with a trailing unit such as `"2px"` is accepted.

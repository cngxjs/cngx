# CNGX2001

## Unknown filter operator

### Why

A filter expression names an operator key that has no evaluation registered: neither a builtin (`eq`, `contains`, `gt`, ...) nor an entry added through `withOperators`. The filter builder cannot test items against it, so the expression evaluates to `false` for every item and the filtered list comes back empty. The warning fires once per key, so a long list does not flood the console.

### Fix

Register the operator with an `evaluate` function:

```typescript
provideFilterBuilderConfig(
  withOperators({ between: { evaluate: (itemValue, value) => /* ... */ true } }),
);
```

If the key is a typo or comes from a stored filter written by an older version, correct or migrate the stored value instead.

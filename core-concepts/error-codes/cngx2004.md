# CNGX2004

## Filter group exceeds the maximum nesting depth

### Why

`addGroup` was called at a path whose new group would sit deeper than the configured `maxNestingDepth` (default 8). The limit applies to programmatic writes the same way it applies to the add-group button, so the call is ignored and the tree stays as it was.

### Fix

Add the group at a shallower path, or raise the limit when deeper trees are intended:

```typescript
provideFilterBuilderConfig(withMaxNestingDepth(12));
```

# CNGX1020

## Duplicate error source key

### Why

An error aggregator received a second error source with a key that is already registered. The new entry replaces the old one (last wins), so the first source no longer contributes errors.

### Fix

Give every source a unique key, for example by combining the field name with the form or row it belongs to.

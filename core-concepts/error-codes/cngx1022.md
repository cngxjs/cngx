# CNGX1022

## Nested option groups

### Why

A `[cngxOptionGroup]` (in a select shell, `<cngx-optgroup>`) contains another option group. The listbox supports one group level only, so the nested group does not render as a group.

### Fix

Flatten the groups into one level. For an arbitrary tree, use `CngxTreeSelect`.

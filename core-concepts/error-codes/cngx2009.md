# CNGX2009

## Filter tree root replaced by an expression

This error is thrown when an internal update of the `@cngx/forms/filter-builder` tree replaces the root group with a node that is not a group.

The filter builder stores its tree as nested `FilterGroup` and `FilterExpression` nodes and addresses a node by a path of child indexes: `[]` is the root group, `[2, 0]` is the first child of the root's third child. The root must always be a group: the presenter, the group directive and every path start from it. The tree utilities that `createFilterBuilderState` runs on refuse a root replacement that would break this, instead of storing a tree no path can address.

### Fixing the error

The public API cannot trigger this error. The state mutators on the root (`setLogic([])`, `toggleNegated([])`, `clear()`) only ever produce a group, and the field, operator and value mutators leave a group unchanged. Seeing `CNGX2009` therefore means a CNGX bug. Open an issue at https://github.com/cngxjs/cngx/issues with the mutator call and the tree it ran on.

### Debugging the error

The message reads `CNGX2009: updateAtPath(): root replacement must remain a FilterGroup`. In a production build the message is the bare code `CNGX2009`; the check still runs there.

The stack trace leads from the state mutator to `updateAtPath`. Note which mutator and which path you called; those two are what the issue needs.

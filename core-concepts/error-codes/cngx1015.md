# CNGX1015

## Non-modal dialog without a live region

### Why

A non-modal `<dialog cngxDialog>` opened with `show()`. Unlike a modal dialog it does not move the screen reader into the dialog, and no `aria-live` region sits next to the trigger, so a screen reader user is not told that it appeared.

### Fix

Add a live region as a sibling of the trigger that announces the dialog:

```html
<button (click)="dlg.open()">Filters</button>
<span aria-live="polite">{{ dlg.lifecycle() === 'open' ? 'Filter panel opened' : '' }}</span>
```

Or open the dialog as modal if the content needs focus.

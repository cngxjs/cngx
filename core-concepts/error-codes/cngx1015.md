# CNGX1015

## Non-modal dialog without a title

This warning is emitted when a `<dialog cngxDialog>` opens as a non-modal dialog and has no title text.

A modal dialog (`showModal()`) moves focus into itself, so a screen reader lands in the dialog and reads it. A non-modal dialog (`show()`, `[modal]="false"`) leaves focus where it was: the page behind it stays interactive, which is the point of a non-modal dialog. `CngxDialog` covers that case itself. Every dialog renders a polite live region inside the `<dialog>` element, and when the dialog reaches the `open` state it writes its title text into that region, so a screen reader announces the title.

That announcement needs text. A non-modal dialog with no `[cngxDialogTitle]`, an empty one, or a title registered by a composed component without text opens unannounced:

```html
<!-- WARNING: no title, so nothing announces the dialog -->
<dialog cngxDialog #filters="cngxDialog" [modal]="false">
  <cngx-filter-panel />
</dialog>
```

A dialog opened through `CngxDialogOpener` with `open(Content, { modal: false })` is checked the same way. Its title comes from a `[cngxDialogTitle]` element inside the content component or template.

### Fixing the warning

#### Option 1: Give the dialog a title

Add a `[cngxDialogTitle]` element with text. It labels the dialog through `aria-labelledby` and is the text the dialog announces on open:

```html
<dialog cngxDialog #filters="cngxDialog" [modal]="false">
  <h2 cngxDialogTitle>{{ filtersTitle() }}</h2>
  <cngx-filter-panel />
</dialog>
```

Route the title through your own i18n, like any other copy. If the design has no visible heading, keep the element and hide it visually with a screen-reader-only class; it still labels and announces the dialog.

#### Option 2: Open the dialog as modal

If the dialog asks for input before the user continues, it is a modal dialog. Drop `[modal]="false"` (or `modal: false` in the opener config): focus moves into the dialog, and the screen reader reads it.

### Debugging the warning

The message names the dialog by its id, for example `CNGX1015: [cngxDialog] non-modal dialog "cngx-dialog-3" opened without a title.`; the id is the `id` attribute on the `<dialog>` element. Search the rendered DOM for that id to find the dialog.

The check runs in development mode only, once per opening of a non-modal dialog, when the dialog reaches the `open` state one frame after `open()`. It reads the title text at the same moment the announcement does, so a title whose text is bound and renders after `open()` is called is checked against that rendered text. A title filled in later than that is reported and is also not announced. A modal dialog is never checked.

# CNGX3001

## No Router for a router-sync directive

### Why

A router-sync directive from `@cngx/ui` is on the page, but the app provides no `Router`. These directives inject the router optionally, so a missing router does not throw: `CngxBreadcrumbRouterSync` and `CngxBreadcrumbSiblingsRouterSync` render an empty trail or sibling list, and `CngxTocRouterSync` neither writes nor reads the URL fragment. The directive stays inactive for the lifetime of the host. The message names the directive and the feature it would enable.

The same condition in the `@cngx/common` router-sync directives (stepper, tabs, query-param sync) has its own code in the `@cngx/common` range.

### Fix

Provide the router in the application config:

```typescript
bootstrapApplication(AppComponent, {
  providers: [provideRouter(routes)],
});
```

If the view is not routed, remove the router-sync attribute (`cngxRouterSync`, `cngxTocRouterSync`) and drive the component through its inputs instead (`[items]` on the breadcrumb bar, `[siblings]` on the siblings menu).

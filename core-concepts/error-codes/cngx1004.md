# CNGX1004

## DOM-event key bound on `[cngxAudioStatus]`

### Why

`[cngxAudioStatus]` plays earcons on async-state transitions (`idle`, `loading`, `pending`, `refreshing`, `success` / `succeeded`, `error` / `failed`). The binding spec contains a DOM-event key such as `click`, which this directive does not listen to.

### Fix

Move the DOM-event keys to `[cngxAudio]` and keep only status keys on `[cngxAudioStatus]`. Both directives can sit on the same host.

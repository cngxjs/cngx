# CNGX1006

## Invalid Date bound to a timestamp

### Why

`<cngx-card-timestamp>` parses its `[date]` input into a `Date`. The bound value produced an Invalid Date, usually a malformed ISO string, so the component renders empty and drops the `datetime` attribute.

### Fix

Check the bound value. Pass a `Date` or a string that `new Date(value)` parses, such as `2026-10-13` or `2026-10-13T09:30:00Z`. If the value can be missing, render the timestamp only when it is set.

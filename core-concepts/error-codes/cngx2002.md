# CNGX2002

## Filter builder has no fields

### Why

The filter builder rendered with an empty `fields` array. Every expression row picks one of these fields, so with none there is nothing to filter by and the builder always shows its empty state.

### Fix

Bind `[fields]` to the list of fields your items can be filtered by. When the list loads asynchronously, render the builder once it has arrived (`@if (fields().length)`) so the first render already sees it.

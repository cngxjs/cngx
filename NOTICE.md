## Material Symbols

- **Used in:** `@cngx/utils`, `projects/utils/icons.ts`
- **What:** the SVG path data of three default glyphs, taken from the
  Material Symbols set at FILL 0, weight 400, optical size 24:

  | cngx constant | Material Symbols name |
  |-|-|
  | `CNGX_ICON_EXCLAMATION` | `exclamation` |
  | `CNGX_ICON_EXCLAMATION_SOLID` | `priority_high` |
  | `CNGX_ICON_QUESTION` | `question_mark` |

  The path geometry is used as published. cngx embeds it as string
  constants and renders it as a filled inline SVG `<path>`.
